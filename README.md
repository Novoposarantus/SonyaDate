# Sonya Date

Романтическая статическая открытка для Сони в стиле `kawaii scrapbook`: розовые карточки, мягкие анимации и шутливое приглашение на свидание с убегающими кнопками.

## Что внутри

- `index.html` — основная разметка открытки
- `styles.css` — стили, композиция, анимации, адаптивность
- `script.js` — логика кнопок, переключение сценария и финальная анимация
- `.github/workflows/deploy-pages.yml` — автодеплой на GitHub Pages через GitHub Actions

## Локальный запуск

Сборка не нужна.

1. Открой папку проекта.
2. Запусти `index.html` в браузере.

Если хочется удобнее редактировать локально, можно открыть проект в VS Code и использовать `Live Server`, но это не обязательно.

## Как выложить на GitHub Pages

В репозитории уже есть workflow для деплоя статического сайта.

### 1. Закоммить и запушь рабочую ветку

Сейчас проект лежит в feature-ветке, поэтому сначала отправь изменения в неё:

```bash
git add .
git commit -m "feat: add Sonya greeting site"
git push
```

### 2. Смёржи изменения в `main`

GitHub Pages workflow в этом репозитории настроен на публикацию из `main`.

Проще всего так:

1. Открой pull request из `feat/sonya-date-card` в `main`
2. Смёржи его

Если позже будешь работать уже прямо в `main`, то достаточно обычного пуша в `main`.

### 3. Включи GitHub Pages

На GitHub:

1. Открой репозиторий `SonyaDate`
2. Перейди в `Settings` → `Pages`
3. В секции `Build and deployment` выбери `Source` → `GitHub Actions`

После этого каждый пуш в `main` будет публиковать сайт автоматически.

## Как будет работать деплой

Workflow:

- запускается при пуше в `main`
- загружает содержимое репозитория как статический сайт
- публикует его в GitHub Pages

Адрес сайта обычно будет таким:

`https://novoposarantus.github.io/SonyaDate/`

## Если хочешь быстро поменять открытку

### Текст

Редактируй `index.html`.

### Цвета

Основные цвета лежат в `:root` внутри `styles.css`.

### Поведение кнопок

Меняется в `script.js`.

## Что можно улучшить позже

- добавить реальные фото вместо декоративных карточек
- вставить музыку
- сделать несколько сценариев шуток
- добавить более личные фразы и ваши внутренние мемы
- сделать отдельный финальный экран после успешного ответа
